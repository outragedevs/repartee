# /quit

## Syntax

    /quit [message]

## Description

Disconnect from all servers and close the application. An optional quit
message is sent to each server. The default includes the Repartee name,
version, and project URL.

## Examples

    /quit
    /quit Goodnight!

## See Also

/disconnect, /close
