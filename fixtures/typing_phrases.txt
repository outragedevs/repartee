# The exact wording of the "X is typing…" status-line phrase.
#
# `typing_phrase` is duplicated verbatim across two crates:
#
#   src/ui/status_line.rs                  (TUI, native)
#   web-ui/src/components/status_line.rs   (web bundle, WASM)
#
# They are separate compilation targets and cannot share code, so this file is
# the tie. Both crates' tests `include_str!` it and assert their own function
# against these literals — so rewording the phrase in ONE crate fails the OTHER
# crate's test, which is the whole point. `make test` runs both.
#
# Format: comma-separated nicks, ` => `, the exact phrase. The empty-list case
# yields `None` and has no string to drift, so each crate asserts it directly.

alice => alice is typing…
alice,bob => alice and bob are typing…
alice,bob,carol => alice, bob and carol are typing…
alice,bob,carol,dave => alice, bob and 2 others are typing…
a,b,c,d,e => a, b and 3 others are typing…
